# Changelog

All notable changes to PyDays. The files to download for each version (with checksums) are on the
[Releases](https://github.com/nokkiee/pydays/releases) page. Version numbers: a change in the
middle number means new features, a change in the last one means fixes and small changes.

## [1.0.0] – 2026-11-24

First release, for Windows 10 / 11 and Linux.

- 30 classes that follow the curriculum of *30 Days Of Python*, from *Introduction* to *Building
  an API* and *Conclusions*, each with a lesson, runnable examples and 3–5 exercises with
  automatic checks, hints and model solutions.
- Interface and all lessons in English, Polish, German, Spanish and French.
- Editor based on Monaco (the editor of VS Code) with a dark theme, Python completions and a
  Problems panel that marks syntax errors as you type.
- Terminal that runs programs in your own Python, answers `input()`, marks tracebacks in the
  editor, and has an interactive Python shell.
- Calendar with study days, streaks and study time, and milestones at 3, 7, 14, 21 and 30
  completed days.
- Sandbox editor for your own experiments.
- Starter code in exercises can be turned off in *Settings → Editor*; the app asks once at the
  first start.
- Installers for Windows (setup and portable), AppImage and .deb for Linux, and a launcher for
  running from source (`npm run install-desktop`).
- Community files: contributing guide, code of conduct, security policy, issue forms and a pull
  request template; automatic tests and builds with a self-test of every built app; checksums
  attached to every release.
