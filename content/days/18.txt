en: ## What is a regular expression?
A **regular expression** (regex) is a small pattern that describes text: “a digit”, “one or more letters”, “something that looks like an e-mail address”. Python's `re` module searches text for such patterns. Write patterns as **raw strings**, `r'...'`, so that backslashes reach the regex unchanged.
pl: ## Czym jest wyrażenie regularne?
**Wyrażenie regularne** (regex) to mały wzorzec opisujący tekst: „cyfra”, „jedna lub więcej liter”, „coś, co wygląda jak adres e-mail”. Moduł `re` w Pythonie szuka takich wzorców w tekście. Wzorce zapisuj jako **surowe napisy**, `r'...'`, żeby ukośniki wsteczne dotarły do wyrażenia bez zmian.
de: ## Was ist ein regulärer Ausdruck?
Ein **regulärer Ausdruck** (Regex) ist ein kleines Muster, das Text beschreibt: „eine Ziffer“, „ein oder mehrere Buchstaben“, „etwas, das wie eine E-Mail-Adresse aussieht“. Das Python-Modul `re` sucht solche Muster in Text. Schreib Muster als **Raw-Strings**, `r'...'`, damit Backslashes unverändert beim Regex ankommen.
es: ## ¿Qué es una expresión regular?
Una **expresión regular** (regex) es un pequeño patrón que describe texto: «una cifra», «una o más letras», «algo que parece una dirección de correo». El módulo `re` de Python busca esos patrones en un texto. Escribe los patrones como **cadenas sin procesar**, `r'...'`, para que las barras invertidas lleguen intactas a la expresión.
fr: ## Qu'est-ce qu'une expression régulière ?
Une **expression régulière** (regex) est un petit motif qui décrit du texte : « un chiffre », « une ou plusieurs lettres », « quelque chose qui ressemble à une adresse e-mail ». Le module `re` de Python cherche de tels motifs dans un texte. Écris les motifs sous forme de **chaînes brutes**, `r'...'`, pour que les barres obliques inverses arrivent telles quelles à la regex.

en: ## Functions of the re module

| Function | What it does |
|---|---|
| `re.match(p, text)` | matches only at the **start** of the text |
| `re.search(p, text)` | finds the **first** match anywhere |
| `re.findall(p, text)` | returns a list of **all** matches |
| `re.split(p, text)` | splits the text at every match |
| `re.sub(p, new, text)` | replaces every match with `new` |

`match` and `search` return a match object or `None`; `group()` gives the matched text and `span()` its position. `re.I` as a flag ignores upper and lower case.

| Funkcja | Co robi |

| `re.findall(p, text)` | zwraca listę **wszystkich** dopasowań |
| `re.split(p, text)` | dzieli tekst w każdym dopasowaniu |
| `re.sub(p, new, text)` | zamienia każde dopasowanie na `new` |

`match` i `search` zwracają obiekt dopasowania albo `None`; `group()` daje dopasowany tekst, a `span()` jego pozycję. Flaga `re.I` każe ignorować wielkość liter.

@code
import re
txt = 'I love to teach Python and JavaScript'
print(re.match('I love', txt))
print(re.match('Python', txt))                 # None – not at the start
m = re.search('python', txt, re.I)
print(m.group(), m.span())
print(re.findall('a', txt))
print(re.split(' ', 'one two  three'))
print(re.sub('Python|JavaScript', 'coding', txt))
@end

A few building blocks go a long way:

| Pattern | Matches |
|---|---|
| `.` | any character except a new line |

@code
import re
txt = 'Call 555-1234 or 555-9876 before 18:30. Prices: 4.99, 12.50'
print(re.findall(r'\d+', txt))                   # every run of digits
print(re.findall(r'\d{3}-\d{4}', txt))           # phone numbers
print(re.findall(r'\d+\.\d+', txt))              # decimal numbers
print(re.findall(r'(\d\d):(\d\d)', txt))         # groups -> tuples
print(re.findall(r'[A-Z]\w*', txt))              # words with a capital letter
print(bool(re.fullmatch(r'[a-z]+', 'python')))   # the whole text must match
@end

@solution
import re

paragraph = 'I love teaching. If you do not love teaching what else can you love. I love Python if you do not love something which can give you all the capabilities to develop an application what else can you love.'


def most_frequent_words(text):
    counts = {}
    for word in re.findall(r'[a-z]+', text.lower()):
        counts[word] = counts.get(word, 0) + 1
    pairs = [(n, w) for w, n in counts.items()]
    return sorted(pairs, key=lambda p: (-p[0], p[1]))


print(most_frequent_words(paragraph)[:5])
@end
@case

expr: most_frequent_words('b a B') == [(2, 'b'), (1, 'a')]
