@md
en: ## Booleans
A boolean is either `True` or `False` – with a capital letter. Comparisons and logical operators produce booleans, and later `if` statements and loops decide what to do based on them.
pl: ## Wartości logiczne
Wartość logiczna (boolean) to `True` (prawda) albo `False` (fałsz) – pisane wielką literą. Porównania i operatory logiczne dają w wyniku wartości logiczne, a później instrukcje `if` i pętle na ich podstawie decydują, co zrobić.
de: ## Wahrheitswerte
Ein Wahrheitswert (Boolean) ist entweder `True` oder `False` – mit großem Anfangsbuchstaben. Vergleiche und logische Operatoren liefern Wahrheitswerte, und später entscheiden `if`-Anweisungen und Schleifen danach, was passiert.
es: ## Booleanos
Un booleano es `True` (verdadero) o `False` (falso), con mayúscula inicial. Las comparaciones y los operadores lógicos producen booleanos, y más adelante las sentencias `if` y los bucles deciden qué hacer según ellos.
fr: ## Les booléens
Un booléen vaut `True` (vrai) ou `False` (faux) – avec une majuscule. Les comparaisons et les opérateurs logiques produisent des booléens, et plus tard les instructions `if` et les boucles décideront quoi faire en fonction d'eux.

@code
print(True)
print(False)
print(type(True))   # <class 'bool'>
@end

@md
en: ## Assignment operators
`=` stores a value in a variable. The combined operators update a variable using its current value: `x += 3` means `x = x + 3`. The same works with `-=`, `*=`, `/=`, `%=`, `//=` and `**=`.
pl: ## Operatory przypisania
`=` zapisuje wartość w zmiennej. Operatory złożone zmieniają zmienną na podstawie jej obecnej wartości: `x += 3` znaczy `x = x + 3`. Tak samo działają `-=`, `*=`, `/=`, `%=`, `//=` i `**=`.
de: ## Zuweisungsoperatoren
`=` speichert einen Wert in einer Variablen. Die kombinierten Operatoren ändern eine Variable anhand ihres aktuellen Wertes: `x += 3` bedeutet `x = x + 3`. Genauso funktionieren `-=`, `*=`, `/=`, `%=`, `//=` und `**=`.
es: ## Operadores de asignación
`=` guarda un valor en una variable. Los operadores combinados actualizan una variable a partir de su valor actual: `x += 3` significa `x = x + 3`. Lo mismo sirve con `-=`, `*=`, `/=`, `%=`, `//=` y `**=`.
fr: ## Les opérateurs d'affectation
`=` range une valeur dans une variable. Les opérateurs combinés modifient une variable à partir de sa valeur actuelle : `x += 3` signifie `x = x + 3`. Cela marche aussi avec `-=`, `*=`, `/=`, `%=`, `//=` et `**=`.

@code
x = 10
x += 3     # 13
x -= 1     # 12
x *= 2     # 24
x //= 5    # 4
x **= 2    # 16
print(x)
@end

en: ## Arithmetic operators

| Operator | Name | Example | Result |
|---|---|---|---|
| `+` | addition | `7 + 2` | `9` |
| `-` | subtraction | `7 - 2` | `5` |
| `*` | multiplication | `7 * 2` | `14` |
| `/` | division | `7 / 2` | `3.5` |
| `%` | modulus (remainder) | `7 % 2` | `1` |
| `//` | floor division | `7 // 2` | `3` |
| `**` | exponentiation | `7 ** 2` | `49` |

As in maths, `**` is evaluated first, then `*`, `/`, `//` and `%`, then `+` and `-`. Use parentheses to change the order.

|---|---|---|---|
| `+` | dodawanie | `7 + 2` | `9` |
| `-` | odejmowanie | `7 - 2` | `5` |
| `*` | mnożenie | `7 * 2` | `14` |
| `/` | dzielenie | `7 / 2` | `3.5` |
| `%` | reszta z dzielenia (modulo) | `7 % 2` | `1` |
| `//` | dzielenie całkowite | `7 // 2` | `3` |
| `**` | potęgowanie | `7 ** 2` | `49` |

Jak w matematyce najpierw liczy się `**`, potem `*`, `/`, `//` i `%`, a na końcu `+` i `-`. Kolejność zmienia się nawiasami.

|---|---|---|---|

| `-` | Subtraktion | `7 - 2` | `5` |

Wie in der Mathematik wird zuerst `**` ausgewertet, dann `*`, `/`, `//` und `%`, dann `+` und `-`. Mit Klammern änderst du die Reihenfolge.
es: ## Operadores aritméticos

| Operador | Nombre | Ejemplo | Resultado |
|---|---|---|---|
| `+` | suma | `7 + 2` | `9` |
| `-` | resta | `7 - 2` | `5` |
| `*` | multiplicación | `7 * 2` | `14` |

| `**` | potencia | `7 ** 2` | `49` |

Como en matemáticas, primero se calcula `**`, luego `*`, `/`, `//` y `%`, y al final `+` y `-`. Usa paréntesis para cambiar el orden.
fr: ## Les opérateurs arithmétiques

Comme en maths, on calcule d'abord `**`, puis `*`, `/`, `//` et `%`, et enfin `+` et `-`. Les parenthèses changent l'ordre.

@code
a = 3

print('a + b =', a + b)
print('a / b =', a / b)
print('a // b =', a // b)
print('a % b =', a % b)
print('a ** b =', a ** b)
print(2 + 3 * 4)       # 14
print((2 + 3) * 4)     # 20

# Body mass index
weight = 75    # kg
height = 1.8   # m
bmi = weight / height ** 2
print('BMI:', round(bmi, 1))
@end

@md
en: ## Comparison operators
Comparisons give `True` or `False`: `==` (equal), `!=` (not equal), `>`, `<`, `>=` and `<=`. Note the difference between `=` (assign a value) and `==` (compare two values).

Python also has `is` / `is not` (are they the very same object?) and `in` / `not in` (is something inside a string, list…?).
pl: ## Operatory porównania
Porównania dają `True` albo `False`: `==` (równe), `!=` (różne), `>`, `<`, `>=` i `<=`. Zwróć uwagę na różnicę między `=` (przypisanie wartości) a `==` (porównanie dwóch wartości).

Python ma też `is` / `is not` (czy to dokładnie ten sam obiekt?) oraz `in` / `not in` (czy coś jest w napisie, liście…?).
de: ## Vergleichsoperatoren
Vergleiche ergeben `True` oder `False`: `==` (gleich), `!=` (ungleich), `>`, `<`, `>=` und `<=`. Achte auf den Unterschied zwischen `=` (Wert zuweisen) und `==` (zwei Werte vergleichen).

Außerdem gibt es `is` / `is not` (ist es genau dasselbe Objekt?) und `in` / `not in` (steckt etwas in einer Zeichenkette, Liste…?).
es: ## Operadores de comparación
Las comparaciones dan `True` o `False`: `==` (igual), `!=` (distinto), `>`, `<`, `>=` y `<=`. Fíjate en la diferencia entre `=` (asignar un valor) y `==` (comparar dos valores).

Python también tiene `is` / `is not` (¿es exactamente el mismo objeto?) e `in` / `not in` (¿está algo dentro de una cadena, una lista…?).
fr: ## Les opérateurs de comparaison
Les comparaisons donnent `True` ou `False` : `==` (égal), `!=` (différent), `>`, `<`, `>=` et `<=`. Attention à la différence entre `=` (affecter une valeur) et `==` (comparer deux valeurs).

Python a aussi `is` / `is not` (est-ce exactement le même objet ?) et `in` / `not in` (quelque chose se trouve-t-il dans une chaîne, une liste… ?).

@code
print(3 > 2)                        # True
print(3 == 2)                       # False
print(3 != 2)                       # True
print(len('mango') == len('avocado'))  # False
print('on' in 'python')             # True
print('A' in 'python')              # False – case matters
print(1 is 1.0, 1 == 1.0)           # False True
@end

@md
en: ## Logical operators
- `and` is `True` only when both sides are `True`;
- `or` is `True` when at least one side is `True`;
- `not` turns `True` into `False` and the other way round.
pl: ## Operatory logiczne
- `and` daje `True` tylko wtedy, gdy obie strony są `True`;
- `or` daje `True`, gdy przynajmniej jedna strona jest `True`;
- `not` zamienia `True` na `False` i odwrotnie.
de: ## Logische Operatoren
- `and` ist nur `True`, wenn beide Seiten `True` sind;
- `or` ist `True`, wenn mindestens eine Seite `True` ist;
- `not` macht aus `True` ein `False` und umgekehrt.
es: ## Operadores lógicos
- `and` es `True` solo cuando los dos lados son `True`;
- `or` es `True` cuando al menos un lado es `True`;
- `not` convierte `True` en `False` y al revés.
fr: ## Les opérateurs logiques
- `and` vaut `True` seulement si les deux côtés valent `True` ;
- `or` vaut `True` si au moins un côté vaut `True` ;
- `not` transforme `True` en `False` et inversement.

@code
age = 20
has_ticket = True
print(age >= 18 and has_ticket)   # True
print(age < 18 or has_ticket)     # True
print(not has_ticket)             # False
print(3 > 2 and 4 > 3 and 5 > 4)  # True
@end
