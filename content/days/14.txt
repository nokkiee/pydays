en: ## Functions are values
In Python a function is an object like any other. You can store it in a variable, put it in a list, pass it as an argument and return it from another function. A function that takes or returns a function is called a **higher-order function**.
pl: ## Funkcje są wartościami
W Pythonie funkcja jest obiektem jak każdy inny. Można ją zapisać w zmiennej, włożyć do listy, przekazać jako argument i zwrócić z innej funkcji. Funkcja, która przyjmuje albo zwraca funkcję, to **funkcja wyższego rzędu**.
de: ## Funktionen sind Werte
In Python ist eine Funktion ein Objekt wie jedes andere. Du kannst sie in einer Variable speichern, in eine Liste packen, als Argument übergeben und aus einer anderen Funktion zurückgeben. Eine Funktion, die eine Funktion nimmt oder zurückgibt, heißt **Funktion höherer Ordnung**.
es: ## Las funciones son valores
En Python una función es un objeto como cualquier otro. Puedes guardarla en una variable, meterla en una lista, pasarla como argumento y devolverla desde otra función. Una función que recibe o devuelve una función se llama **función de orden superior**.
fr: ## Les fonctions sont des valeurs
En Python, une fonction est un objet comme un autre. On peut la ranger dans une variable, la mettre dans une liste, la passer en argument et la renvoyer depuis une autre fonction. Une fonction qui reçoit ou renvoie une fonction s'appelle une **fonction d'ordre supérieur**.

@code
def sum_numbers(nums):
    return sum(nums)

def higher_order_function(f, values):
    return f(values)

print(higher_order_function(sum_numbers, [1, 2, 3, 4, 5]))   # 15

def square(x):
    return x ** 2

def cube(x):
    return x ** 3

def pick(kind):
    return square if kind == 'square' else cube

f = pick('cube')
print(f(3))      # 27
@end

en: ## Closures
A function defined inside another function can use the variables of the outer one – even after the outer function has returned. Such an inner function is a **closure**: it remembers the values it was created with.
pl: ## Domknięcia
Funkcja zdefiniowana w innej funkcji może korzystać ze zmiennych tej zewnętrznej – nawet po tym, jak zewnętrzna funkcja już się zakończyła. Taka wewnętrzna funkcja to **domknięcie** (closure): pamięta wartości, z którymi powstała.
de: ## Closures
Eine Funktion, die in einer anderen Funktion definiert ist, kann die Variablen der äußeren verwenden – sogar, nachdem die äußere Funktion schon zurückgekehrt ist. So eine innere Funktion heißt **Closure**: Sie merkt sich die Werte, mit denen sie entstanden ist.
es: ## Clausuras
Una función definida dentro de otra puede usar las variables de la exterior, incluso después de que la exterior haya terminado. Esa función interior es una **clausura** (closure): recuerda los valores con los que se creó.
fr: ## Les fermetures
Une fonction définie dans une autre fonction peut utiliser les variables de la fonction extérieure – même après que celle-ci a terminé. Une telle fonction intérieure est une **fermeture** (closure) : elle se souvient des valeurs avec lesquelles elle a été créée.

@code
def make_multiplier(factor):
    def multiply(x):
        return x * factor
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5), triple(5))     # 10 15
@end

en: ## Decorators
A **decorator** is a function that takes a function and returns a new one that adds something around it. The `@name` line above a `def` applies it: writing `@uppercase` above `greet` means the same as `greet = uppercase(greet)`. The inner wrapper usually takes `*args, **kwargs` so that it works with any function.
pl: ## Dekoratory
**Dekorator** to funkcja, która przyjmuje funkcję i zwraca nową, dokładającą coś wokół niej. Wiersz `@name` nad `def` go stosuje: napisanie `@uppercase` nad `greet` znaczy to samo co `greet = uppercase(greet)`. Wewnętrzna funkcja opakowująca zwykle przyjmuje `*args, **kwargs`, żeby działała z każdą funkcją.
de: ## Dekoratoren
Ein **Dekorator** ist eine Funktion, die eine Funktion nimmt und eine neue zurückgibt, die etwas drumherum ergänzt. Die Zeile `@name` über einem `def` wendet ihn an: `@uppercase` über `greet` bedeutet dasselbe wie `greet = uppercase(greet)`. Die innere Hüllfunktion nimmt meist `*args, **kwargs`, damit sie mit jeder Funktion funktioniert.
es: ## Decoradores
Un **decorador** es una función que recibe una función y devuelve otra nueva que añade algo a su alrededor. La línea `@name` encima de un `def` lo aplica: escribir `@uppercase` encima de `greet` equivale a `greet = uppercase(greet)`. La función envoltorio interior suele recibir `*args, **kwargs` para funcionar con cualquier función.
fr: ## Les décorateurs
Un **décorateur** est une fonction qui reçoit une fonction et en renvoie une nouvelle qui ajoute quelque chose autour. La ligne `@name` au-dessus d'un `def` l'applique : écrire `@uppercase` au-dessus de `greet` revient à écrire `greet = uppercase(greet)`. La fonction enveloppe intérieure prend en général `*args, **kwargs` pour fonctionner avec n'importe quelle fonction.

@code
def uppercase(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs).upper()
    return wrapper

def exclaim(func):
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs) + '!'
    return wrapper

@exclaim
@uppercase
def greet(name):
    return f'welcome, {name}'

print(greet('Anna'))      # WELCOME, ANNA!
@end

en: ## map, filter and reduce
Three classic higher-order functions work on whole sequences:

| Function | What it does |
|---|---|
| `map(f, items)` | applies `f` to every item |
| `filter(f, items)` | keeps the items for which `f` returns true |
| `reduce(f, items)` | combines the items into one value, two at a time – from the `functools` module |

`map` and `filter` return lazy objects; wrap them in `list()` to see the result. A comprehension often does the same job and is just as fine.
pl: ## map, filter i reduce
Trzy klasyczne funkcje wyższego rzędu działają na całych ciągach:

| Funkcja | Co robi |
|---|---|
| `map(f, items)` | stosuje `f` do każdego elementu |
| `filter(f, items)` | zostawia elementy, dla których `f` zwraca prawdę |
| `reduce(f, items)` | łączy elementy w jedną wartość, po dwa naraz – z modułu `functools` |

`map` i `filter` zwracają leniwe obiekty; żeby zobaczyć wynik, opakuj je w `list()`. Wyrażenie listowe często robi to samo i też jest w porządku.
de: ## map, filter und reduce
Drei klassische Funktionen höherer Ordnung arbeiten mit ganzen Folgen:

| Funktion | Was sie macht |
|---|---|
| `map(f, items)` | wendet `f` auf jedes Element an |
| `filter(f, items)` | behält die Elemente, für die `f` wahr liefert |
| `reduce(f, items)` | fasst die Elemente paarweise zu einem Wert zusammen – aus dem Modul `functools` |

`map` und `filter` liefern träge (lazy) Objekte; pack sie in `list()`, um das Ergebnis zu sehen. Eine Comprehension erledigt oft dasselbe und ist genauso gut.
es: ## map, filter y reduce
Tres funciones de orden superior clásicas trabajan con secuencias enteras:

| Función | Qué hace |
|---|---|
| `map(f, items)` | aplica `f` a cada elemento |
| `filter(f, items)` | se queda con los elementos para los que `f` devuelve verdadero |
| `reduce(f, items)` | combina los elementos en un solo valor, de dos en dos; está en el módulo `functools` |

`map` y `filter` devuelven objetos perezosos; envuélvelos en `list()` para ver el resultado. Una comprensión suele hacer lo mismo y es igual de válida.
fr: ## map, filter et reduce
Trois fonctions d'ordre supérieur classiques travaillent sur des séquences entières :

| Fonction | Ce qu'elle fait |
|---|---|
| `map(f, items)` | applique `f` à chaque élément |
| `filter(f, items)` | garde les éléments pour lesquels `f` renvoie vrai |
| `reduce(f, items)` | combine les éléments en une seule valeur, deux par deux – dans le module `functools` |

`map` et `filter` renvoient des objets paresseux ; entoure-les de `list()` pour voir le résultat. Une compréhension fait souvent la même chose et convient tout aussi bien.

@code
from functools import reduce

numbers = [1, 2, 3, 4, 5]
print(list(map(lambda x: x ** 2, numbers)))          # [1, 4, 9, 16, 25]
print(list(map(str.upper, ['asabeneh', 'lidiya'])))
print(list(filter(lambda x: x % 2 == 0, numbers)))   # [2, 4]
print(reduce(lambda a, b: a + b, numbers))           # 15
@end

@hint

fr: La fonction intérieure modifie une variable de la fonction extérieure, elle a donc besoin de `nonlocal count` avant `count += 1`.
@starter
def make_counter():
    count = 0

    def counter():
        pass

    return counter
@end
@solution
def make_counter():
    count = 0

    def counter():
        nonlocal count
        count += 1
        return count

    return counter


c = make_counter()
print(c(), c(), c())
@end
@case
expr: (lambda c: [c(), c(), c()])(make_counter()) == [1, 2, 3]
expr: (lambda a, b: (a(), a(), b(), a()))(make_counter(), make_counter()) == (1, 2, 1, 3)
