en: ## Describing data
**Statistics** turns a pile of numbers into a few that describe it. The most common ones:

| Measure | Meaning |
|---|---|
| mean | the average: the sum divided by the count |
| median | the middle value of the sorted data – not pulled by extreme values |
| mode | the most frequent value |
| range | the largest value minus the smallest |
| variance, standard deviation | how far the values typically are from the mean |
| quartiles | the values that cut the sorted data into four equal parts |

Python's `statistics` module computes all of these.
pl: ## Opisywanie danych

| Miara | Znaczenie |
|---|---|
| średnia | suma podzielona przez liczbę wartości |
| mediana | środkowa wartość posortowanych danych – skrajne wartości jej nie przesuwają |
| dominanta | najczęstsza wartość |
| rozstęp | największa wartość minus najmniejsza |
| wariancja, odchylenie standardowe | jak daleko od średniej leżą zwykle wartości |
| kwartyle | wartości, które dzielą posortowane dane na cztery równe części |

Moduł `statistics` w Pythonie oblicza je wszystkie.

Les **statistiques** transforment un tas de nombres en quelques-uns qui le décrivent. Les plus courants :

|---|---|

@code
import statistics as st

ages = [31, 26, 34, 37, 27, 26, 32, 32, 26, 27, 27, 24, 32, 33, 27, 25, 26, 38, 37, 31, 34, 24, 33, 29, 26]

print('range:   ', max(ages) - min(ages))

en: ## Frequency
How often each value occurs is its **frequency**. `collections.Counter` counts the items of a list in one step, and `most_common()` returns them from the most frequent. Dividing by the number of values gives each value's share as a percentage.
pl: ## Częstość
To, jak często występuje dana wartość, to jej **częstość**. `collections.Counter` liczy elementy listy w jednym kroku, a `most_common()` zwraca je od najczęstszego. Dzielenie przez liczbę wartości daje udział każdej wartości w procentach.
de: ## Häufigkeit
Wie oft ein Wert vorkommt, ist seine **Häufigkeit**. `collections.Counter` zählt die Elemente einer Liste in einem Schritt, und `most_common()` gibt sie vom häufigsten an zurück. Teilt man durch die Anzahl der Werte, erhält man den Anteil jedes Werts in Prozent.
es: ## Frecuencia
Las veces que aparece un valor son su **frecuencia**. `collections.Counter` cuenta los elementos de una lista de una vez, y `most_common()` los devuelve empezando por el más frecuente. Dividir entre el número de valores da la proporción de cada valor en porcentaje.
fr: ## Fréquence
Le nombre de fois qu'une valeur apparaît est sa **fréquence**. `collections.Counter` compte les éléments d'une liste en une seule étape, et `most_common()` les renvoie du plus fréquent au moins fréquent. Diviser par le nombre de valeurs donne la part de chaque valeur en pourcentage.

@code
from collections import Counter

ages = [31, 26, 34, 37, 27, 26, 32, 32, 26, 27, 27, 24, 32, 33, 27, 25, 26, 38, 37, 31, 34, 24, 33, 29, 26]
counts = Counter(ages)
for age, n in counts.most_common(3):
    print(age, n, f'{n / len(ages) * 100:.0f}%')
for age in sorted(counts):
    print(f'{age}: {"#" * counts[age]}')
@end

@solution
from collections import Counter

ages = [31, 26, 34, 37, 27, 26, 32, 32, 26, 27, 27, 24, 32, 33, 27, 25, 26, 38, 37, 31, 34, 24, 33, 29, 26]


def frequency_distribution(data):
    counts = Counter(data)
    pairs = [(n / len(data) * 100, value) for value, n in counts.items()]
    return sorted(pairs, reverse=True)


print(frequency_distribution(ages))

@solution
import statistics

salaries = [4100, 3900, 4300, 4000, 4250, 3950, 15000, 4150, 4050, 1200]


def outliers(data):
    q1, q2, q3 = statistics.quantiles(data, n=4)
    iqr = q3 - q1
    low = q1 - 1.5 * iqr
    high = q3 + 1.5 * iqr
    return sorted(x for x in data if x < low or x > high)


print(outliers(salaries))
@end
@case

expr: outliers([1, 2, 3, 4, 5, 6, 7, 8]) == []
