en: ## What is pip?
The standard library is big, but thousands of other packages – for data analysis, web servers, games, machine learning – are published on **PyPI**, the Python Package Index. **pip** is the tool that downloads and installs them.

pip runs in your system's terminal (Command Prompt or PowerShell on Windows, Terminal on macOS and Linux) – not in the Python shell. `python -m pip` makes sure you use the pip that belongs to the same Python as this app (on Windows `py -m pip` also works):

```
python -m pip install requests
python -m pip list
python -m pip show requests
python -m pip install --upgrade requests
python -m pip uninstall requests
```

en: ## requirements.txt
A project usually lists its packages in a file called `requirements.txt`, one per line, often with an exact version after `==`. `pip freeze` prints the installed packages in that format, and `pip install -r requirements.txt` installs everything in the file. Lines starting with `#` are comments.

```
python -m pip freeze > requirements.txt
python -m pip install -r requirements.txt
```

@solution
def parse_requirements(text):
    result = {}
    for line in text.splitlines():
        line = line.strip()
        if not line or line.startswith('#'):
            continue
        if '==' in line:
            name, version = line.split('==', 1)
            result[name.strip().lower()] = version.strip()
        else:
            result[line.lower()] = None
    return result


with open('requirements.txt', encoding='utf-8') as f:
    packages = parse_requirements(f.read())
print(packages)
@end
