en: ## HTTP requests and responses
Every exchange has two parts. The **request** has a **method**, a URL, **headers** (extra information such as the data format) and sometimes a **body**. The **response** has a **status code**, headers and a body. The methods say what you want to do:

| Method | Used to |
|---|---|
| `GET` | read data |
| `POST` | create something new |
| `PUT`, `PATCH` | replace or change something |
| `DELETE` | remove something |

The status code says how it went: `2xx` success (`200` OK, `201` Created), `3xx` redirection, `4xx` a mistake in the request (`400` Bad Request, `404` Not Found), `5xx` an error on the server.
pl: ## Żądania i odpowiedzi HTTP
Każda wymiana ma dwie części. **Żądanie** ma **metodę**, adres URL, **nagłówki** (dodatkowe informacje, np. format danych) i czasem **treść** (body). **Odpowiedź** ma **kod statusu**, nagłówki i treść. Metody mówią, co chcesz zrobić:

| Metoda | Służy do |
|---|---|
| `GET` | odczytu danych |
| `POST` | utworzenia czegoś nowego |
| `PUT`, `PATCH` | zastąpienia albo zmiany czegoś |
| `DELETE` | usunięcia czegoś |

Kod statusu mówi, jak poszło: `2xx` sukces (`200` OK, `201` Created), `3xx` przekierowanie, `4xx` błąd w żądaniu (`400` Bad Request, `404` Not Found), `5xx` błąd po stronie serwera.
de: ## HTTP-Anfragen und -Antworten
Jeder Austausch hat zwei Teile. Die **Anfrage** hat eine **Methode**, eine URL, **Header** (Zusatzinformationen wie das Datenformat) und manchmal einen **Body**. Die **Antwort** hat einen **Statuscode**, Header und einen Body. Die Methoden sagen, was du vorhast:

| Methode | Wofür |
|---|---|
| `GET` | Daten lesen |
| `POST` | etwas Neues anlegen |
| `PUT`, `PATCH` | etwas ersetzen oder ändern |
| `DELETE` | etwas entfernen |

Der Statuscode sagt, wie es gelaufen ist: `2xx` Erfolg (`200` OK, `201` Created), `3xx` Weiterleitung, `4xx` ein Fehler in der Anfrage (`400` Bad Request, `404` Not Found), `5xx` ein Fehler auf dem Server.
es: ## Peticiones y respuestas HTTP
Cada intercambio tiene dos partes. La **petición** tiene un **método**, una URL, **cabeceras** (información extra, como el formato de los datos) y a veces un **cuerpo**. La **respuesta** tiene un **código de estado**, cabeceras y un cuerpo. Los métodos dicen lo que quieres hacer:

| Método | Sirve para |
|---|---|
| `GET` | leer datos |
| `POST` | crear algo nuevo |
| `PUT`, `PATCH` | sustituir o cambiar algo |
| `DELETE` | borrar algo |

El código de estado dice cómo ha ido: `2xx` éxito (`200` OK, `201` Created), `3xx` redirección, `4xx` un error en la petición (`400` Bad Request, `404` Not Found), `5xx` un error en el servidor.
fr: ## Requêtes et réponses HTTP
Chaque échange a deux parties. La **requête** a une **méthode**, une URL, des **en-têtes** (des informations en plus, comme le format des données) et parfois un **corps**. La **réponse** a un **code d'état**, des en-têtes et un corps. Les méthodes disent ce que tu veux faire :

| Méthode | Sert à |
|---|---|
| `GET` | lire des données |
| `POST` | créer quelque chose |
| `PUT`, `PATCH` | remplacer ou modifier quelque chose |
| `DELETE` | supprimer quelque chose |

Le code d'état dit comment ça s'est passé : `2xx` succès (`200` OK, `201` Created), `3xx` redirection, `4xx` une erreur dans la requête (`400` Bad Request, `404` Not Found), `5xx` une erreur côté serveur.

def status_class(code):

@solution
import json


def parse_response(raw):
    head, body = raw.split('\n\n', 1)
    lines = head.splitlines()
    status = int(lines[0].split()[1])
    headers = {}
    for line in lines[1:]:
        name, value = line.split(': ', 1)
        headers[name.lower()] = value
    return status, headers, body

from urllib.parse import urlencode


def build_url(base, params):
    kept = {k: v for k, v in params.items() if v is not None}
    if not kept:
        return base
    return base + '?' + urlencode(kept)

@solution
import json
from collections import Counter

with open('cats.json', encoding='utf-8') as f:
    cats = json.load(f)


def middle(text):
    low, high = text.split(' - ')
    return (float(low) + float(high)) / 2


weights = [middle(cat['weight']['metric']) for cat in cats]
heaviest = max(cats, key=lambda c: middle(c['weight']['metric']))['name']
mean_weight = sum(weights) / len(weights)
top_origin = Counter(cat['origin'] for cat in cats).most_common(1)[0][0]
print(weights, heaviest, mean_weight, top_origin)
@end
