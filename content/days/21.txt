en: ## Classes and objects
Everything in Python is an **object**: a number, a string, a list. Each object has a type – its **class** – which decides what data it holds and what it can do. With `class` you can make your own types. A class is like a blueprint, and every object made from it is an **instance**.

en: ## The constructor and methods
`__init__` is called automatically when an object is created – it is the **constructor**. Its first parameter, `self`, is the new object itself; `self.name = name` stores a value in it as an **attribute**. Functions defined in a class are **methods**. They also take `self` first, and Python passes it for you: `p.person_info()`.

Funkcje zdefiniowane w klasie to **metody**. One też przyjmują `self` jako pierwszy parametr, a Python podaje go sam: `p.person_info()`.

Constructor parameters can have default values, like any function's. Methods can change the object's attributes – for example add to a list stored in it. Each instance has its own attributes, so changing one object does not touch the others.

`__str__` is a special method that decides what `print(obj)` shows.

en: ## Inheritance
A class can **inherit** from another: `class Student(Person)` gets all of `Person`'s attributes and methods and can add its own. A method with the same name in the child class **overrides** the parent's. `super()` calls the parent's version – most often `super().__init__(...)` in the child's constructor.
pl: ## Dziedziczenie
Klasa może **dziedziczyć** po innej: `class Student(Person)` dostaje wszystkie atrybuty i metody klasy `Person` i może dodać własne. Metoda o tej samej nazwie w klasie potomnej **nadpisuje** metodę rodzica. `super()` wywołuje wersję rodzica – najczęściej `super().__init__(...)` w konstruktorze klasy potomnej.
de: ## Vererbung
Eine Klasse kann von einer anderen **erben**: `class Student(Person)` bekommt alle Attribute und Methoden von `Person` und kann eigene hinzufügen. Eine Methode mit demselben Namen in der Kindklasse **überschreibt** die der Elternklasse. `super()` ruft die Version der Elternklasse auf – meist `super().__init__(...)` im Konstruktor der Kindklasse.
es: ## Herencia
Una clase puede **heredar** de otra: `class Student(Person)` recibe todos los atributos y métodos de `Person` y puede añadir los suyos. Un método con el mismo nombre en la clase hija **sobrescribe** el del padre. `super()` llama a la versión del padre; lo más habitual es `super().__init__(...)` en el constructor de la clase hija.
fr: ## L'héritage
Une classe peut **hériter** d'une autre : `class Student(Person)` reçoit tous les attributs et méthodes de `Person` et peut en ajouter. Une méthode de même nom dans la classe enfant **redéfinit** celle du parent. `super()` appelle la version du parent – le plus souvent `super().__init__(...)` dans le constructeur de la classe enfant.

@code
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def describe(self):
        return f'{self.name}, {self.age}'

class Student(Person):
    def __init__(self, name, age, school):
        super().__init__(name, age)
        self.school = school

    def describe(self):
        return super().describe() + f', studies at {self.school}'

s = Student('Anna', 20, 'University of Warsaw')
print(s.describe())
print(isinstance(s, Student), isinstance(s, Person))
@end

@solution
ages = [31, 26, 34, 37, 27, 26, 32, 32, 26, 27, 27, 24, 32, 33, 27, 25, 26, 38, 37, 31, 34, 24, 33, 29, 26]


class Statistics:
    def __init__(self, data):
        self.data = data

    def count(self):
        return len(self.data)

    def total(self):
        return sum(self.data)

    def min(self):
        return min(self.data)

    def max(self):
        return max(self.data)

    def range(self):
        return self.max() - self.min()

    def mean(self):
        return self.total() / self.count()

    def median(self):
        s = sorted(self.data)
        n = len(s)
        if n % 2:
            return s[n // 2]
        return (s[n // 2 - 1] + s[n // 2]) / 2


data = Statistics(ages)
print(data.count(), data.total(), data.min(), data.max(), data.range(), data.mean(), data.median())
@end

expr: Statistics(ages).median() == 29
expr: Statistics([4, 1, 3, 2]).median() == 2.5

class Point:
    def __init__(self, x=0, y=0):
        self.x = x
        self.y = y

        return ((self.x - other.x) ** 2 + (self.y - other.y) ** 2) ** 0.5
