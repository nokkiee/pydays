en: ## Creating strings
A string is text in quotes: single, double, or triple quotes for text that spans several lines. `len()` gives the number of characters.
pl: ## Tworzenie napisów
Napis to tekst w cudzysłowie: pojedynczym, podwójnym albo potrójnym – ten ostatni pozwala zapisać tekst w kilku wierszach. `len()` podaje liczbę znaków.
de: ## Zeichenketten erzeugen
Eine Zeichenkette (String) ist Text in Anführungszeichen: einfach, doppelt oder dreifach für Text über mehrere Zeilen. `len()` liefert die Anzahl der Zeichen.
es: ## Crear cadenas
Una cadena es texto entre comillas: simples, dobles o triples para un texto de varias líneas. `len()` da el número de caracteres.
fr: ## Créer des chaînes
Une chaîne est du texte entre guillemets : simples, doubles ou triples pour un texte sur plusieurs lignes. `len()` donne le nombre de caractères.

@code
letter = 'P'

multiline = '''I am a teacher and enjoy teaching.
I didn't find anything more rewarding than empowering people.'''
print(letter, len(letter))
print(greeting, len(greeting))
print(multiline)
@end

en: ## Joining strings and escape sequences
`+` joins (concatenates) strings and `*` repeats them. Inside a string, a backslash starts an **escape sequence**: `\n` is a new line, `\t` a tab, `\\` a backslash and `\'` or `\"` a quote.
pl: ## Łączenie napisów i sekwencje ucieczki
`+` łączy napisy (konkatenacja), a `*` je powtarza. W napisie ukośnik wsteczny zaczyna **sekwencję ucieczki**: `\n` to nowy wiersz, `\t` tabulator, `\\` ukośnik wsteczny, a `\'` lub `\"` cudzysłów.
de: ## Zeichenketten verbinden und Escape-Sequenzen
`+` verbindet (verkettet) Zeichenketten, `*` wiederholt sie. In einer Zeichenkette beginnt ein Backslash eine **Escape-Sequenz**: `\n` ist ein Zeilenumbruch, `\t` ein Tabulator, `\\` ein Backslash und `\'` oder `\"` ein Anführungszeichen.
es: ## Unir cadenas y secuencias de escape
`+` une (concatena) cadenas y `*` las repite. Dentro de una cadena, la barra invertida empieza una **secuencia de escape**: `\n` es un salto de línea, `\t` un tabulador, `\\` una barra invertida y `\'` o `\"` una comilla.
fr: ## Assembler des chaînes et séquences d'échappement
`+` assemble (concatène) des chaînes et `*` les répète. Dans une chaîne, une barre oblique inverse commence une **séquence d'échappement** : `\n` est un saut de ligne, `\t` une tabulation, `\\` une barre oblique inverse et `\'` ou `\"` un guillemet.

en: ## Formatting strings
To put values into text, use an **f-string**: write `f` before the quote and the expressions in braces. Inside the braces you can add a format: `{pi:.2f}` shows two decimal places. The older `'{} {}'.format(a, b)` and `'%s' % a` styles still work, and you will see them in other people's code.
pl: ## Formatowanie napisów
Do wstawiania wartości w tekst służy **f-string**: przed cudzysłowem pisze się `f`, a wyrażenia w nawiasach klamrowych. W nawiasie można dodać format: `{pi:.2f}` pokazuje dwa miejsca po przecinku. Starsze sposoby, `'{} {}'.format(a, b)` i `'%s' % a`, nadal działają i można je spotkać w cudzym kodzie.
de: ## Zeichenketten formatieren
Um Werte in Text einzusetzen, nimmst du einen **f-String**: `f` vor das Anführungszeichen, die Ausdrücke in geschweifte Klammern. In der Klammer kannst du ein Format angeben: `{pi:.2f}` zeigt zwei Nachkommastellen. Die älteren Schreibweisen `'{} {}'.format(a, b)` und `'%s' % a` funktionieren weiterhin, und du siehst sie in fremdem Code.
es: ## Formatear cadenas
Para meter valores en un texto se usa una **f-string**: se escribe `f` antes de la comilla y las expresiones entre llaves. Dentro de las llaves puedes añadir un formato: `{pi:.2f}` muestra dos decimales. Los estilos antiguos `'{} {}'.format(a, b)` y `'%s' % a` siguen funcionando y los verás en código ajeno.
fr: ## Formater des chaînes
Pour insérer des valeurs dans un texte, utilise une **f-string** : écris `f` avant le guillemet et les expressions entre accolades. Dans les accolades, tu peux ajouter un format : `{pi:.2f}` affiche deux décimales. Les anciens styles `'{} {}'.format(a, b)` et `'%s' % a` fonctionnent encore, et tu les croiseras dans le code des autres.

@code
name = 'Asabeneh'
age = 250
pi = 3.14159
print(f'{name} is {age} years old.')
print(f'{age} + 10 = {age + 10}')
print(f'Pi is about {pi:.2f}')
print('{} is {} years old.'.format(name, age))
print('%s is %d years old.' % (name, age))
@end

en: ## Indexes and slices
A string is a sequence of characters, numbered from `0`. Negative indexes count from the end: `-1` is the last character. A **slice** `text[start:end]` takes the characters from `start` up to, but not including, `end`; a third number is the step, so `text[::-1]` reverses a string.
pl: ## Indeksy i wycinki
Napis to ciąg znaków numerowanych od `0`. Indeksy ujemne liczą od końca: `-1` to ostatni znak. **Wycinek** `text[start:end]` bierze znaki od `start` aż do `end`, ale bez niego; trzecia liczba to krok, więc `text[::-1]` odwraca napis.
de: ## Indizes und Slices
Eine Zeichenkette ist eine Folge von Zeichen, nummeriert ab `0`. Negative Indizes zählen vom Ende: `-1` ist das letzte Zeichen. Ein **Slice** `text[start:end]` nimmt die Zeichen ab `start` bis ausschließlich `end`; eine dritte Zahl ist die Schrittweite, also dreht `text[::-1]` eine Zeichenkette um.
es: ## Índices y porciones
Una cadena es una secuencia de caracteres numerados desde `0`. Los índices negativos cuentan desde el final: `-1` es el último carácter. Una **porción** (slice) `text[start:end]` toma los caracteres desde `start` hasta `end`, sin incluirlo; un tercer número es el paso, así que `text[::-1]` invierte una cadena.
fr: ## Indices et tranches
Une chaîne est une suite de caractères numérotés à partir de `0`. Les indices négatifs comptent depuis la fin : `-1` est le dernier caractère. Une **tranche** `text[start:end]` prend les caractères de `start` jusqu'à `end` exclu ; un troisième nombre est le pas, donc `text[::-1]` inverse une chaîne.

@code
language = 'Python'
print(language[0])      # P
print(language[-1])     # n
print(language[0:3])    # Pyt
print(language[3:])     # hon
print(language[::2])    # Pto
print(language[::-1])   # nohtyP
@end

en: ## String methods
Strings have many built-in **methods**, called with a dot: `text.upper()`. Strings never change – a method returns a new string. The most useful ones:

| Method | What it does |
|---|---|
| `upper()`, `lower()`, `title()`, `capitalize()` | change the case |
| `strip()` | remove spaces from both ends |
| `replace(old, new)` | replace text |
| `split(sep)` | cut into a list of parts |
| `'sep'.join(list)` | glue a list of strings together |
| `count(x)`, `find(x)`, `index(x)` | count, find a position |
| `startswith(x)`, `endswith(x)` | check the beginning or end |
| `isdigit()`, `isalpha()`, `isalnum()` | check what the characters are |
pl: ## Metody napisów
Napisy mają wiele wbudowanych **metod**, które wywołuje się po kropce: `text.upper()`. Napis nigdy się nie zmienia – metoda zwraca nowy napis. Najprzydatniejsze:

| Metoda | Co robi |
|---|---|
| `upper()`, `lower()`, `title()`, `capitalize()` | zmienia wielkość liter |
| `strip()` | usuwa spacje z obu końców |
| `replace(old, new)` | zamienia tekst |
| `split(sep)` | dzieli na listę części |
| `'sep'.join(list)` | skleja listę napisów |
| `count(x)`, `find(x)`, `index(x)` | liczy, znajduje pozycję |
| `startswith(x)`, `endswith(x)` | sprawdza początek albo koniec |
| `isdigit()`, `isalpha()`, `isalnum()` | sprawdza, jakie to znaki |
de: ## String-Methoden

| `split(sep)` | zerlegt in eine Liste von Teilen |
| `'sep'.join(list)` | fügt eine Liste von Zeichenketten zusammen |
| `count(x)`, `find(x)`, `index(x)` | zählt, findet eine Position |

Las cadenas tienen muchos **métodos** integrados que se llaman con un punto: `text.upper()`. Las cadenas nunca cambian: un método devuelve una cadena nueva. Los más útiles:

fr: ## Les méthodes des chaînes
Les chaînes ont de nombreuses **méthodes** intégrées, appelées avec un point : `text.upper()`. Une chaîne ne change jamais – une méthode renvoie une nouvelle chaîne. Les plus utiles :

| Méthode | Ce qu'elle fait |
|---|---|

| `strip()` | retire les espaces aux deux bouts |
| `replace(old, new)` | remplace du texte |
| `split(sep)` | découpe en une liste de morceaux |
| `'sep'.join(list)` | recolle une liste de chaînes |
| `count(x)`, `find(x)`, `index(x)` | comptent, trouvent une position |

| `isdigit()`, `isalpha()`, `isalnum()` | vérifient la nature des caractères |

@code
challenge = 'thirty days of python'
print(challenge.upper())              # THIRTY DAYS OF PYTHON
print(challenge.title())              # Thirty Days Of Python
print(challenge.count('y'))           # 3
print(challenge.find('days'))         # 7
print(challenge.replace('python', 'coding'))
print(challenge.split())              # ['thirty', 'days', 'of', 'python']
print('-'.join(['a', 'b', 'c']))      # a-b-c
print('   padded   '.strip())         # padded
print('2026'.isdigit(), 'abc'.isalpha())
@end
