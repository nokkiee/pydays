en: ## How a web application works
When you open a page, the browser sends an **HTTP request** for a path such as `/about` to a server. The server runs code that decides what to send back – usually HTML – and replies with a **response**. A **web framework** does the plumbing: it receives requests, calls the function you wrote for that path, and sends what the function returns.

Python has several frameworks; **Flask** is small and easy to start with, **Django** is larger and comes with much more built in. Install Flask with `python -m pip install flask`.

Gdy otwierasz stronę, przeglądarka wysyła do serwera **żądanie HTTP** o ścieżkę, na przykład `/about`. Serwer uruchamia kod, który decyduje, co odesłać – zwykle HTML – i odpowiada **odpowiedzią**. **Framework webowy** zajmuje się całą instalacją rurową: odbiera żądania, wywołuje funkcję napisaną przez ciebie dla danej ścieżki, i odsyła to, co ona zwróci.

Python ma kilka frameworków; **Flask** jest mały i łatwy na początek, **Django** jest większy i ma znacznie więcej wbudowanych funkcji. Flaska zainstalujesz przez `python -m pip install flask`.

en: ## Templates and static files
Writing HTML inside Python strings gets messy fast. Flask keeps pages in **templates** – HTML files in a folder called `templates`, written in the **Jinja** language. `{{ name }}` inserts a value, `{% for %}` and `{% if %}` add loops and conditions, and `render_template('home.html', name='Anna')` fills a template in. CSS, images and JavaScript go into a folder called `static`.

A typical project looks like this:

```
my_site/
├── app.py
├── requirements.txt
├── templates/
│   ├── layout.html
│   └── home.html
└── static/
    └── css/
        └── main.css
```

@solution
routes = {}


def route(path):
    def register(func):
        routes[path] = func
        return func
    return register


def handle(path):
    view = routes.get(path)
    if view is None:
        return '404 Not Found'
    return view()


@route('/')
def home():
    return '<h1>Home</h1>'


@route('/about')
def about():
    return '<h1>About</h1>'


@route('/contact')
def contact():
    return '<h1>Contact</h1>'


for p in ['/', '/about', '/nothing']:
    print(p, handle(p))
@end

expr: handle('/') == '<h1>Home</h1>' and handle('/contact') == '<h1>Contact</h1>'
expr: handle('/missing') == '404 Not Found'
expr: home() == '<h1>Home</h1>'

@solution
def match_route(pattern, path):
    p_parts = pattern.split('/')
    parts = path.split('/')
    if len(p_parts) != len(parts):
        return None
    params = {}
    for p, part in zip(p_parts, parts):
        if p.startswith('<') and p.endswith('>'):
            if not part:
                return None
            params[p[1:-1]] = part
        elif p != part:
            return None
    return params


print(match_route('/hello/<name>', '/hello/Anna'))
