@md
en: ## if and else
Until now every line ran, one after another. A **condition** lets the program choose. After `if` comes an expression and a colon; the indented block below it runs only when the expression is true. `else:` gives the block for every other case.

Indentation is part of the syntax in Python: the lines of a block must be indented the same – four spaces is the convention.
pl: ## if i else
Dotąd wykonywał się każdy wiersz, jeden po drugim. **Warunek** pozwala programowi wybierać. Po `if` jest wyrażenie i dwukropek; wcięty blok pod spodem wykonuje się tylko wtedy, gdy wyrażenie jest prawdziwe. `else:` to blok na wszystkie pozostałe przypadki.

W Pythonie wcięcia są częścią składni: wiersze jednego bloku muszą mieć takie samo wcięcie – zwyczajowo cztery spacje.
de: ## if und else
Bisher lief jede Zeile, eine nach der anderen. Eine **Bedingung** lässt das Programm wählen. Nach `if` kommen ein Ausdruck und ein Doppelpunkt; der eingerückte Block darunter läuft nur, wenn der Ausdruck wahr ist. `else:` ist der Block für alle anderen Fälle.

Einrückung gehört in Python zur Syntax: Die Zeilen eines Blocks müssen gleich weit eingerückt sein – üblich sind vier Leerzeichen.
es: ## if y else
Hasta ahora se ejecutaba cada línea, una tras otra. Una **condición** permite que el programa elija. Después de `if` va una expresión y dos puntos; el bloque sangrado de debajo solo se ejecuta si la expresión es verdadera. `else:` es el bloque para todos los demás casos.

En Python la sangría forma parte de la sintaxis: las líneas de un bloque deben tener la misma sangría; lo habitual son cuatro espacios.
fr: ## if et else
Jusqu'ici, chaque ligne s'exécutait, l'une après l'autre. Une **condition** permet au programme de choisir. Après `if` viennent une expression et deux-points ; le bloc indenté en dessous ne s'exécute que si l'expression est vraie. `else:` donne le bloc pour tous les autres cas.

En Python, l'indentation fait partie de la syntaxe : les lignes d'un bloc doivent avoir la même indentation – par convention, quatre espaces.

@code
a = 3
if a > 0:
    print('A is a positive number')
else:
    print('A is not a positive number')
@end

@md
en: ## elif – more than two cases
With several possibilities, add `elif` (“else if”) branches. Python checks them from the top and runs only the **first** one that is true; `else` catches the rest.
pl: ## elif – więcej niż dwa przypadki
Przy kilku możliwościach dodaje się gałęzie `elif` („else if”). Python sprawdza je od góry i wykonuje tylko **pierwszą** prawdziwą; `else` łapie resztę.
de: ## elif – mehr als zwei Fälle
Bei mehreren Möglichkeiten fügst du `elif`-Zweige hinzu („else if“). Python prüft sie von oben und führt nur den **ersten** wahren aus; `else` fängt den Rest ab.
es: ## elif: más de dos casos
Cuando hay varias posibilidades, se añaden ramas `elif` («else if»). Python las comprueba de arriba abajo y ejecuta solo la **primera** que sea verdadera; `else` recoge el resto.
fr: ## elif – plus de deux cas
Quand il y a plusieurs possibilités, on ajoute des branches `elif` (« else if »). Python les vérifie de haut en bas et n'exécute que la **première** qui est vraie ; `else` attrape le reste.

@code
temperature = 18
if temperature >= 25:
    print('Hot')
elif temperature >= 15:
    print('Warm')
elif temperature >= 5:
    print('Cool')
else:
    print('Cold')
@end

@md
en: ## Nesting and combining conditions
A condition can sit inside another one, but deep nesting is hard to read. Often `and`, `or` and `not` say the same thing more simply: `and` needs both sides true, `or` at least one, and `not` flips a value.
pl: ## Zagnieżdżanie i łączenie warunków
Warunek może siedzieć w innym warunku, ale głębokie zagnieżdżenia trudno się czyta. Często `and`, `or` i `not` mówią to samo prościej: `and` wymaga, żeby obie strony były prawdziwe, `or` – co najmniej jedna, a `not` odwraca wartość.
de: ## Bedingungen verschachteln und verknüpfen
Eine Bedingung kann in einer anderen stecken, aber tiefe Verschachtelung ist schwer zu lesen. Oft sagen `and`, `or` und `not` dasselbe einfacher: `and` braucht zwei wahre Seiten, `or` mindestens eine, und `not` dreht einen Wert um.
es: ## Anidar y combinar condiciones
Una condición puede ir dentro de otra, pero anidar mucho cuesta de leer. A menudo `and`, `or` y `not` dicen lo mismo de forma más simple: `and` necesita que los dos lados sean verdaderos, `or` al menos uno, y `not` invierte un valor.
fr: ## Imbriquer et combiner des conditions
Une condition peut se trouver dans une autre, mais une imbrication profonde est difficile à lire. Souvent, `and`, `or` et `not` disent la même chose plus simplement : `and` exige que les deux côtés soient vrais, `or` au moins un, et `not` inverse une valeur.

@code
a = 7
# nested
if a > 0:
    if a % 2 == 0:
        print('A is a positive and even integer')
    else:
        print('A is a positive odd number')
# combined with and
if a > 0 and a % 2 == 1:
    print('Positive and odd')
user = 'James'
access_level = 3
if user == 'admin' or access_level >= 4:
    print('Access granted')
else:
    print('Access denied')
@end

@md
en: ## Short conditions
For a simple choice between two values there is a one-line form: `value_if_true if condition else value_if_false`. Use it for short expressions only – a full `if` block is clearer for anything longer.
pl: ## Krótkie warunki
Do prostego wyboru między dwiema wartościami jest forma jednowierszowa: `value_if_true if condition else value_if_false`. Używaj jej tylko do krótkich wyrażeń – przy czymś dłuższym pełny blok `if` jest czytelniejszy.
de: ## Kurze Bedingungen
Für eine einfache Wahl zwischen zwei Werten gibt es eine Kurzform in einer Zeile: `value_if_true if condition else value_if_false`. Nimm sie nur für kurze Ausdrücke – bei allem Längeren ist ein ganzer `if`-Block klarer.
es: ## Condiciones cortas
Para elegir entre dos valores existe una forma de una sola línea: `value_if_true if condition else value_if_false`. Úsala solo para expresiones cortas; para algo más largo, un bloque `if` completo se lee mejor.
fr: ## Conditions courtes
Pour un simple choix entre deux valeurs, il existe une forme sur une ligne : `value_if_true if condition else value_if_false`. Réserve-la aux expressions courtes – pour tout ce qui est plus long, un vrai bloc `if` est plus clair.

@code
age = 17
status = 'adult' if age >= 18 else 'minor'
print(status)
n = 4
print('even' if n % 2 == 0 else 'odd')
@end
