en: ## What is a module?
A **module** is simply a Python file whose functions and variables you use in another file. Any `.py` file can be a module: if there is a file `mymodule.py` next to your program, `import mymodule` makes everything in it available as `mymodule.name`.

This lesson comes with the file `mymodule.py`, shown below. It is saved next to your program, so the examples and exercises can import it.
pl: ## Czym jest moduł?
**Moduł** to po prostu plik Pythona, z którego funkcji i zmiennych korzystasz w innym pliku. Modułem może być każdy plik `.py`: jeśli obok twojego programu leży plik `mymodule.py`, `import mymodule` udostępnia wszystko, co w nim jest, jako `mymodule.name`.

Do tej lekcji należy plik `mymodule.py`, pokazany poniżej. Jest zapisany obok twojego programu, więc przykłady i ćwiczenia mogą go zaimportować.

en: ## Ways to import
You can import single names with `from module import name` and then use them without the prefix. `as` gives a module or a name a shorter alias. `from module import *` imports everything, but it makes it hard to see where a name came from – better avoid it.
pl: ## Sposoby importowania
Pojedyncze nazwy importuje się przez `from module import name` i potem używa ich bez przedrostka. `as` nadaje modułowi albo nazwie krótszy alias. `from module import *` importuje wszystko, ale wtedy trudno zobaczyć, skąd pochodzi dana nazwa – lepiej tego unikać.
de: ## Arten zu importieren

On peut importer des noms isolés avec `from module import name` et les utiliser ensuite sans préfixe. `as` donne à un module ou à un nom un alias plus court. `from module import *` importe tout, mais on ne voit plus d'où vient chaque nom – mieux vaut l'éviter.

@solution
import random
import string


def random_user_id():
    chars = string.ascii_lowercase + string.digits
    result = ''
    for _ in range(6):
        result += random.choice(chars)
    return result


print(random_user_id())
@end

expr: len({random_user_id() for _ in range(50)}) > 45

def rgb_color_gen():
    r = random.randint(0, 255)
    g = random.randint(0, 255)
    b = random.randint(0, 255)

@end
@solution
import random


def shuffled_digits():
    digits = list(range(10))
    random.shuffle(digits)
    return digits


print(shuffled_digits())
@end
@case

expr: len({tuple(shuffled_digits()) for _ in range(20)}) > 15
