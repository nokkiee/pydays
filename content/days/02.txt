en: ## Variables
A **variable** is a name for a value stored in the computer's memory. You create it with `=`, the assignment operator: the name on the left, the value on the right. After that you can use the name instead of the value.

Rules for names:
- they may contain letters, digits and underscores, but can't start with a digit;
- they are case-sensitive: `age` and `Age` are two different variables;
- they can't be Python keywords such as `if`, `for` or `class`.

By convention Python uses **snake_case**: lowercase words joined by underscores, like `first_name`.
pl: ## Zmienne
**Zmienna** to nazwa wartości zapisanej w pamięci komputera. Tworzy się ją znakiem `=`, czyli operatorem przypisania: nazwa po lewej, wartość po prawej. Potem można używać nazwy zamiast wartości.

Zasady nazywania:
- nazwa może zawierać litery, cyfry i podkreślenia, ale nie może zaczynać się od cyfry;
- wielkość liter ma znaczenie: `age` i `Age` to dwie różne zmienne;
- nazwą nie może być słowo kluczowe Pythona, np. `if`, `for` albo `class`.

Zwyczajowo w Pythonie stosuje się **snake_case**: małe litery i słowa łączone podkreśleniem, np. `first_name`.
de: ## Variablen
Eine **Variable** ist ein Name für einen Wert im Speicher des Computers. Du erzeugst sie mit `=`, dem Zuweisungsoperator: links der Name, rechts der Wert. Danach kannst du den Namen statt des Wertes verwenden.

Regeln für Namen:
- sie dürfen Buchstaben, Ziffern und Unterstriche enthalten, aber nicht mit einer Ziffer beginnen;
- Groß- und Kleinschreibung zählt: `age` und `Age` sind zwei verschiedene Variablen;
- sie dürfen keine Python-Schlüsselwörter wie `if`, `for` oder `class` sein.

Üblich ist in Python **snake_case**: kleingeschriebene Wörter, verbunden durch Unterstriche, etwa `first_name`.
es: ## Variables
Una **variable** es un nombre para un valor guardado en la memoria del ordenador. Se crea con `=`, el operador de asignación: el nombre a la izquierda y el valor a la derecha. Después puedes usar el nombre en lugar del valor.

Reglas para los nombres:
- pueden contener letras, dígitos y guiones bajos, pero no pueden empezar por un dígito;
- distinguen mayúsculas de minúsculas: `age` y `Age` son dos variables distintas;
- no pueden ser palabras clave de Python como `if`, `for` o `class`.

Por convención, Python usa **snake_case**: palabras en minúsculas unidas por guiones bajos, como `first_name`.

en: ## Converting between types
To calculate with what the user typed, convert it first: `int()` makes a whole number, `float()` a decimal number and `str()` text. Converting text that isn't a number, like `int('abc')`, raises a `ValueError`.
pl: ## Zamiana typów
Żeby liczyć na tym, co wpisał użytkownik, najpierw trzeba to zamienić: `int()` tworzy liczbę całkowitą, `float()` liczbę zmiennoprzecinkową, a `str()` napis. Zamiana tekstu, który nie jest liczbą, np. `int('abc')`, zgłasza błąd `ValueError`.
de: ## Typen umwandeln
Um mit dem zu rechnen, was der Benutzer eingetippt hat, wandelst du es zuerst um: `int()` macht eine ganze Zahl, `float()` eine Kommazahl und `str()` einen Text. Text, der keine Zahl ist, umzuwandeln, etwa `int('abc')`, löst einen `ValueError` aus.
es: ## Convertir entre tipos
Para calcular con lo que escribió el usuario, primero hay que convertirlo: `int()` crea un número entero, `float()` un número decimal y `str()` un texto. Convertir un texto que no es un número, como `int('abc')`, lanza un `ValueError`.
fr: ## Convertir les types
Pour calculer avec ce que l'utilisateur a tapé, il faut d'abord le convertir : `int()` donne un nombre entier, `float()` un nombre décimal et `str()` du texte. Convertir un texte qui n'est pas un nombre, comme `int('abc')`, lève une `ValueError`.

@code
num_str = '10'
num_int = int(num_str)
print(num_int + 5)            # 15

num_float = float('9.81')
print(num_float * 2)          # 19.62

print(int(9.99))              # 9 – int() cuts off the decimal part
print(str(250) + ' years')    # '250 years'
print(list('Python'))         # ['P', 'y', 't', 'h', 'o', 'n']
@end

en: ## Numbers
Python has three kinds of numbers: **integers** (`int`, like `-3`, `0`, `250`), **floating-point numbers** (`float`, like `3.14` or `-0.5`) and **complex numbers** (`complex`, like `1 + 2j`). Dividing with `/` always gives a float, even when the result is whole: `10 / 2` is `5.0`.
pl: ## Liczby
Python ma trzy rodzaje liczb: **całkowite** (`int`, np. `-3`, `0`, `250`), **zmiennoprzecinkowe** (`float`, np. `3.14` albo `-0.5`) i **zespolone** (`complex`, np. `1 + 2j`). Dzielenie operatorem `/` zawsze daje liczbę zmiennoprzecinkową, nawet gdy wynik jest całkowity: `10 / 2` to `5.0`.
de: ## Zahlen
Python kennt drei Arten von Zahlen: **ganze Zahlen** (`int`, etwa `-3`, `0`, `250`), **Gleitkommazahlen** (`float`, etwa `3.14` oder `-0.5`) und **komplexe Zahlen** (`complex`, etwa `1 + 2j`). Die Division mit `/` ergibt immer eine Gleitkommazahl, auch wenn das Ergebnis ganz ist: `10 / 2` ist `5.0`.
es: ## Números
Python tiene tres clases de números: **enteros** (`int`, como `-3`, `0`, `250`), **de coma flotante** (`float`, como `3.14` o `-0.5`) y **complejos** (`complex`, como `1 + 2j`). Dividir con `/` siempre da un float, aunque el resultado sea entero: `10 / 2` es `5.0`.
fr: ## Les nombres
Python a trois sortes de nombres : les **entiers** (`int`, comme `-3`, `0`, `250`), les **nombres à virgule flottante** (`float`, comme `3.14` ou `-0.5`) et les **nombres complexes** (`complex`, comme `1 + 2j`). La division avec `/` donne toujours un float, même quand le résultat est entier : `10 / 2` vaut `5.0`.
