en: ## Opening a file
`open(name, mode)` opens a file. The **mode** says what you want to do:

| Mode | Meaning |
|---|---|
| `'r'` | read (the default); the file must exist |
| `'w'` | write; creates the file or **empties** an existing one |
| `'a'` | append to the end; creates the file if needed |
| `'x'` | create; fails if the file already exists |

Use a `with` block: it closes the file for you when the block ends, even after an error. Pass `encoding='utf-8'` so that letters such as ą, ü, é or ñ are read correctly on every system.

This lesson comes with a few files, shown below – they are saved next to your program.

en: ## Reading
`read()` gives the whole file as one string, `readline()` one line at a time, and `readlines()` a list of lines. Looping over the file object reads it line by line, which also works for big files. Each line ends with `'\n'`; `strip()` removes it, or `read().splitlines()` gives lines without it.
pl: ## Odczyt
`read()` daje cały plik jako jeden napis, `readline()` – po jednym wierszu, a `readlines()` – listę wierszy. Pętla po obiekcie pliku czyta go wiersz po wierszu, co działa także dla dużych plików. Każdy wiersz kończy się znakiem `'\n'`; `strip()` go usuwa, a `read().splitlines()` daje wiersze bez niego.
de: ## Lesen
`read()` liefert die ganze Datei als eine Zeichenkette, `readline()` jeweils eine Zeile und `readlines()` eine Liste von Zeilen. Eine Schleife über das Dateiobjekt liest Zeile für Zeile, was auch bei großen Dateien funktioniert. Jede Zeile endet mit `'\n'`; `strip()` entfernt es, oder `read().splitlines()` liefert die Zeilen ohne.
es: ## Leer
`read()` da el archivo entero como una cadena, `readline()` una línea cada vez y `readlines()` una lista de líneas. Recorrer el objeto archivo con un bucle lo lee línea a línea, lo que también sirve para archivos grandes. Cada línea termina en `'\n'`; `strip()` lo quita, o `read().splitlines()` da las líneas sin él.
fr: ## Lire
`read()` donne tout le fichier sous forme d'une seule chaîne, `readline()` une ligne à la fois, et `readlines()` une liste de lignes. Une boucle sur l'objet fichier le lit ligne par ligne, ce qui marche aussi pour les gros fichiers. Chaque ligne se termine par `'\n'` ; `strip()` le retire, ou `read().splitlines()` donne les lignes sans lui.

en: ## Writing
Opening with `'w'` creates the file – or replaces what was in it – and `write()` puts text into it. Unlike `print`, `write` does not add a new line, so add `'\n'` yourself. `'a'` keeps the old content and adds to the end. The `os` module can check whether a file exists and delete it.
pl: ## Zapis
Otwarcie w trybie `'w'` tworzy plik – albo zastępuje jego zawartość – a `write()` wpisuje do niego tekst. W odróżnieniu od `print` metoda `write` nie dodaje nowego wiersza, więc dopisz `'\n'` sam. `'a'` zachowuje starą zawartość i dopisuje na końcu. Moduł `os` potrafi sprawdzić, czy plik istnieje, i go usunąć.
de: ## Schreiben
Öffnen mit `'w'` legt die Datei an – oder ersetzt ihren Inhalt –, und `write()` schreibt Text hinein. Anders als `print` fügt `write` keinen Zeilenumbruch an, also setz `'\n'` selbst. `'a'` behält den alten Inhalt und hängt ans Ende an. Das Modul `os` kann prüfen, ob eine Datei existiert, und sie löschen.
es: ## Escribir
Abrir con `'w'` crea el archivo (o sustituye su contenido) y `write()` escribe texto en él. A diferencia de `print`, `write` no añade un salto de línea, así que pon tú el `'\n'`. `'a'` conserva el contenido anterior y añade al final. El módulo `os` puede comprobar si un archivo existe y borrarlo.
fr: ## Écrire
Ouvrir avec `'w'` crée le fichier – ou remplace son contenu – et `write()` y écrit du texte. Contrairement à `print`, `write` n'ajoute pas de saut de ligne, ajoute donc `'\n'` toi-même. `'a'` garde l'ancien contenu et ajoute à la fin. Le module `os` peut vérifier si un fichier existe et le supprimer.

@code
import os
with open('notes.txt', 'w', encoding='utf-8') as f:
    f.write('First line\n')
    f.write('Second line\n')
with open('notes.txt', 'a', encoding='utf-8') as f:
    f.write('Added later\n')
with open('notes.txt', encoding='utf-8') as f:
    print(f.read())
print(os.path.exists('notes.txt'))
os.remove('notes.txt')
print(os.path.exists('notes.txt'))
@end

en: ## CSV files
**CSV** (comma-separated values) is a simple table format: one row per line, values separated by commas, often with a header row. The `csv` module handles quotes and commas inside values for you. `csv.DictReader` gives each row as a dictionary keyed by the header.
pl: ## Pliki CSV
**CSV** (comma-separated values, wartości rozdzielone przecinkami) to prosty format tabeli: jeden wiersz na linię, wartości rozdzielone przecinkami, często z wierszem nagłówka. Moduł `csv` sam radzi sobie z cudzysłowami i przecinkami wewnątrz wartości. `csv.DictReader` daje każdy wiersz jako słownik z kluczami z nagłówka.
de: ## CSV-Dateien
**CSV** (comma-separated values, kommagetrennte Werte) ist ein einfaches Tabellenformat: eine Zeile pro Datensatz, Werte durch Kommas getrennt, oft mit einer Kopfzeile. Das Modul `csv` kümmert sich um Anführungszeichen und Kommas in Werten. `csv.DictReader` liefert jede Zeile als Dictionary mit den Spaltennamen als Schlüsseln.
es: ## Archivos CSV
**CSV** (comma-separated values, valores separados por comas) es un formato de tabla sencillo: una fila por línea, valores separados por comas y a menudo una fila de cabecera. El módulo `csv` se ocupa de las comillas y las comas dentro de los valores. `csv.DictReader` da cada fila como un diccionario cuyas claves son las de la cabecera.
fr: ## Les fichiers CSV
**CSV** (comma-separated values, valeurs séparées par des virgules) est un format de tableau simple : une ligne par enregistrement, des valeurs séparées par des virgules, souvent avec une ligne d'en-tête. Le module `csv` gère pour toi les guillemets et les virgules à l'intérieur des valeurs. `csv.DictReader` donne chaque ligne sous forme de dictionnaire dont les clés sont celles de l'en-tête.

en: ## JSON
**JSON** is the most common format for exchanging data between programs and over the web. It looks almost like Python dictionaries and lists. `json.load(file)` reads JSON from a file into Python objects and `json.dump(obj, file)` writes them back; `json.loads` and `json.dumps` do the same with strings. `indent=2` makes the output readable.
pl: ## JSON
**JSON** to najpopularniejszy format wymiany danych między programami i w sieci.
