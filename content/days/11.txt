@md
en: ## Defining a function
A **function** is a named block of code that you can run whenever you need it. You define it with `def`, a name, brackets and a colon; the indented body follows. Defining a function does not run it – **calling** it by name with brackets does.
pl: ## Definiowanie funkcji
**Funkcja** to nazwany blok kodu, który można uruchomić, kiedy tylko trzeba. Definiuje się ją słowem `def`, nazwą, nawiasami i dwukropkiem; dalej idzie wcięte ciało. Samo zdefiniowanie funkcji jej nie uruchamia – robi to **wywołanie** po nazwie z nawiasami.
de: ## Eine Funktion definieren
Eine **Funktion** ist ein benannter Codeblock, den du ausführen kannst, wann immer du ihn brauchst. Du definierst sie mit `def`, einem Namen, Klammern und einem Doppelpunkt; danach folgt der eingerückte Rumpf. Das Definieren führt die Funktion nicht aus – das macht erst der **Aufruf** mit Namen und Klammern.
es: ## Definir una función
Una **función** es un bloque de código con nombre que puedes ejecutar siempre que lo necesites. Se define con `def`, un nombre, paréntesis y dos puntos; después va el cuerpo sangrado. Definir una función no la ejecuta: lo hace la **llamada**, con su nombre y paréntesis.
fr: ## Définir une fonction
Une **fonction** est un bloc de code nommé que tu peux exécuter chaque fois que tu en as besoin. On la définit avec `def`, un nom, des parenthèses et deux-points ; le corps indenté suit. Définir une fonction ne l'exécute pas – c'est l'**appel**, par son nom suivi de parenthèses, qui le fait.

def generate_full_name():

    print(first_name + ' ' + last_name)

generate_full_name()
generate_full_name()

en: ## Parameters and return values
**Parameters** are the names in the brackets; the values you pass in a call are the **arguments**. `return` sends a result back to the caller and ends the function. A function without `return` gives back `None`.

Printing and returning are different: `print` only shows a value, `return` hands it over so the rest of the program can use it.
pl: ## Parametry i wartości zwracane
**Parametry** to nazwy w nawiasach; wartości podane przy wywołaniu to **argumenty**. `return` odsyła wynik do miejsca wywołania i kończy funkcję. Funkcja bez `return` zwraca `None`.

Wypisanie i zwrócenie to co innego: `print` tylko pokazuje wartość, a `return` ją oddaje, żeby reszta programu mogła z niej skorzystać.
de: ## Parameter und Rückgabewerte
**Parameter** sind die Namen in den Klammern; die Werte, die du beim Aufruf übergibst, sind die **Argumente**. `return` gibt ein Ergebnis an den Aufrufer zurück und beendet die Funktion. Eine Funktion ohne `return` liefert `None`.

Ausgeben und Zurückgeben sind verschieden: `print` zeigt einen Wert nur an, `return` reicht ihn weiter, damit der Rest des Programms ihn nutzen kann.
es: ## Parámetros y valores devueltos
Los **parámetros** son los nombres entre paréntesis; los valores que pasas al llamar son los **argumentos**. `return` devuelve un resultado a quien llamó y termina la función. Una función sin `return` devuelve `None`.

Imprimir y devolver no es lo mismo: `print` solo muestra un valor, `return` lo entrega para que el resto del programa pueda usarlo.
fr: ## Paramètres et valeurs de retour
Les **paramètres** sont les noms entre parenthèses ; les valeurs passées lors de l'appel sont les **arguments**. `return` renvoie un résultat à l'appelant et termine la fonction. Une fonction sans `return` renvoie `None`.

Afficher et renvoyer, ce n'est pas pareil : `print` ne fait que montrer une valeur, `return` la transmet pour que le reste du programme puisse s'en servir.

@code
def square(x):
    return x * x

def area_of_rectangle(width, height):
    return width * height

result = square(4) + area_of_rectangle(2, 3)
print(result)      # 22

def no_return():
    print('Hi')

print(no_return())  # Hi, then None
@end

@md
en: ## Keyword and default arguments
Arguments can be passed by name – then their order does not matter: `greet(name='Anna', greeting='Hi')`. A parameter can have a **default value**, used when the caller leaves it out. Parameters with defaults go after those without.
pl: ## Argumenty nazwane i domyślne
Argumenty można przekazywać po nazwie – wtedy kolejność nie ma znaczenia: `greet(name='Anna', greeting='Hi')`. Parametr może mieć **wartość domyślną**, używaną, gdy wywołujący go pominie. Parametry z wartościami domyślnymi idą po tych bez nich.
de: ## Schlüsselwort- und Standardargumente
Argumente kannst du mit Namen übergeben – dann ist die Reihenfolge egal: `greet(name='Anna', greeting='Hi')`. Ein Parameter kann einen **Standardwert** haben, der gilt, wenn der Aufrufer ihn weglässt. Parameter mit Standardwert stehen hinter denen ohne.
es: ## Argumentos con nombre y por defecto
Los argumentos se pueden pasar por nombre, y entonces el orden da igual: `greet(name='Anna', greeting='Hi')`. Un parámetro puede tener un **valor por defecto**, que se usa cuando quien llama lo omite. Los parámetros con valor por defecto van detrás de los que no lo tienen.
fr: ## Arguments nommés et valeurs par défaut
Les arguments peuvent être passés par leur nom – leur ordre n'a alors plus d'importance : `greet(name='Anna', greeting='Hi')`. Un paramètre peut avoir une **valeur par défaut**, utilisée quand l'appelant l'omet. Les paramètres avec valeur par défaut viennent après ceux qui n'en ont pas.

@code
def greet(name, greeting='Hello'):
    return f'{greeting}, {name}!'

print(greet('Anna'))
print(greet('Tom', 'Good morning'))
print(greet(greeting='Hi', name='Maria'))

def weight_of_object(mass, gravity=9.81):
    return f'{mass * gravity:.2f} N'

print(weight_of_object(100))
print(weight_of_object(100, 1.62))   # on the Moon
@end

@md
en: ## Any number of arguments
A parameter with a star, `*args`, collects any number of positional arguments into a tuple. With two stars, `**kwargs` collects keyword arguments into a dictionary. Functions can also be passed to other functions like any other value – more about that on day 14.
pl: ## Dowolna liczba argumentów
Parametr z gwiazdką, `*args`, zbiera dowolną liczbę argumentów pozycyjnych w krotkę. Z dwiema gwiazdkami, `**kwargs`, zbiera argumenty nazwane w słownik. Funkcje można też przekazywać do innych funkcji jak każdą inną wartość – więcej o tym w dniu 14.
de: ## Beliebig viele Argumente
Ein Parameter mit Stern, `*args`, sammelt beliebig viele Positionsargumente in einem Tupel. Mit zwei Sternen sammelt `**kwargs` Schlüsselwortargumente in einem Dictionary. Funktionen kannst du außerdem wie jeden anderen Wert an andere Funktionen übergeben – mehr dazu an Tag 14.
es: ## Cualquier número de argumentos
Un parámetro con asterisco, `*args`, recoge cualquier número de argumentos posicionales en una tupla. Con dos asteriscos, `**kwargs` recoge los argumentos con nombre en un diccionario. Las funciones también se pueden pasar a otras funciones como cualquier otro valor; más sobre esto el día 14.
fr: ## Un nombre quelconque d'arguments
Un paramètre étoilé, `*args`, rassemble un nombre quelconque d'arguments positionnels dans un tuple. Avec deux étoiles, `**kwargs` rassemble les arguments nommés dans un dictionnaire. On peut aussi passer des fonctions à d'autres fonctions, comme n'importe quelle valeur – on en reparle le jour 14.

@code
def sum_all_nums(*nums):
    total = 0
    for num in nums:
        total += num
    return total

print(sum_all_nums(2, 3, 5))        # 10

def describe(**info):
    for key, value in info.items():
        print(key, '=', value)

describe(name='Anna', age=30)

def apply(func, value):
    return func(value)

print(apply(len, 'Python'))         # 6
@end

@starter
def convert_celsius_to_fahrenheit(c):
    pass

    pass
@end
@solution
def convert_celsius_to_fahrenheit(c):
    return c * 9 / 5 + 32


def check_season(month):
    month = month.strip().title()
    if month in ['September', 'October', 'November']:
        return 'Autumn'
    if month in ['December', 'January', 'February']:
        return 'Winter'
    if month in ['March', 'April', 'May']:
        return 'Spring'
    return 'Summer'


print(convert_celsius_to_fahrenheit(100), check_season('May'))
@end
@case
expr: convert_celsius_to_fahrenheit(0) == 32
expr: convert_celsius_to_fahrenheit(100) == 212
expr: convert_celsius_to_fahrenheit(-40) == -40
expr: [check_season(m) for m in ['October', 'January', 'April', 'August']] == ['Autumn', 'Winter', 'Spring', 'Summer']

@hint

pl: Zacznij od `result = []` i dla każdego elementu użyj `result.insert(0, item)`.

@starter

    pass
@end
@solution
def reverse_list(items):
    result = []
    for item in items:
        result.insert(0, item)
    return result


print(reverse_list([1, 2, 3, 4, 5]))

    return sum(nums) / len(nums)
