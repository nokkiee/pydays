en: ## The Python shell
Python can also run code line by line in its **interactive shell** (also called the REPL: read, evaluate, print, loop). Press **Python shell** above the terminal and type `2 + 3`, then Enter: the answer appears right away. It's handy for trying small things. Type `exit()` to leave it.

## Comments
Everything after `#` on a line is a **comment**: Python ignores it. Comments explain the code to people. For a longer explanation you can use a text in triple quotes; Python treats it as a string that nobody uses.
pl: ## Powłoka Pythona
Python potrafi też wykonywać kod wiersz po wierszu w **powłoce interaktywnej** (zwanej też REPL: read, evaluate, print, loop – wczytaj, oblicz, wypisz, powtórz). Kliknij **Powłoka Pythona** nad terminalem, wpisz `2 + 3` i naciśnij Enter: wynik pojawi się od razu. To wygodne miejsce do szybkich prób. Wpisz `exit()`, żeby z niej wyjść.
