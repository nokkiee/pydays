@md
en: ## List comprehension
A **list comprehension** builds a new list from another sequence in a single expression: `[expression for item in iterable]`. It does the same as a `for` loop that appends to an empty list, in one line.
pl: ## Wyrażenia listowe
**Wyrażenie listowe** (list comprehension) buduje nową listę z innego ciągu w jednym wyrażeniu: `[expression for item in iterable]`. Robi to samo co pętla `for` dopisująca do pustej listy, tylko w jednym wierszu.
de: ## List Comprehension
Eine **List Comprehension** baut in einem einzigen Ausdruck eine neue Liste aus einer anderen Folge: `[expression for item in iterable]`. Sie macht dasselbe wie eine `for`-Schleife, die an eine leere Liste anhängt – in einer Zeile.
es: ## Listas por comprensión
Una **lista por comprensión** crea una lista nueva a partir de otra secuencia en una sola expresión: `[expression for item in iterable]`. Hace lo mismo que un bucle `for` que va añadiendo a una lista vacía, en una línea.
fr: ## Les listes en compréhension
Une **liste en compréhension** construit une nouvelle liste à partir d'une autre séquence en une seule expression : `[expression for item in iterable]`. Elle fait la même chose qu'une boucle `for` qui ajoute à une liste vide, en une ligne.

@code
# with a loop
squares = []
for i in range(6):
    squares.append(i * i)
print(squares)

# the same with a comprehension
squares = [i * i for i in range(6)]
print(squares)

letters = [ch for ch in 'Python']
print(letters)
pairs = [(i, i * i) for i in range(4)]
print(pairs)
@end

@md
en: ## Filtering with if
An `if` at the end keeps only the items that pass the condition: `[x for x in items if condition]`. To choose between two values instead, put a short condition at the front: `[a if condition else b for x in items]`.
pl: ## Filtrowanie przez if
`if` na końcu zostawia tylko te elementy, które spełniają warunek: `[x for x in items if condition]`. Żeby zamiast tego wybierać między dwiema wartościami, wstaw krótki warunek na początek: `[a if condition else b for x in items]`.
de: ## Filtern mit if
Ein `if` am Ende behält nur die Elemente, die die Bedingung erfüllen: `[x for x in items if condition]`. Willst du stattdessen zwischen zwei Werten wählen, setz eine kurze Bedingung nach vorn: `[a if condition else b for x in items]`.
es: ## Filtrar con if
Un `if` al final se queda solo con los elementos que cumplen la condición: `[x for x in items if condition]`. Para elegir entre dos valores, pon una condición corta al principio: `[a if condition else b for x in items]`.
fr: ## Filtrer avec if
Un `if` à la fin ne garde que les éléments qui remplissent la condition : `[x for x in items if condition]`. Pour choisir plutôt entre deux valeurs, place une courte condition au début : `[a if condition else b for x in items]`.

@code
numbers = [-4, -3, -2, -1, 0, 2, 4, 6]
evens = [n for n in numbers if n % 2 == 0]
positives = [n for n in numbers if n > 0]
signs = ['+' if n > 0 else '-' if n < 0 else '0' for n in numbers]
print(evens)
print(positives)
print(signs)
@end

@md
en: ## Nested lists and other comprehensions
Two `for` parts in one comprehension work like nested loops – the first is the outer one. That is the quickest way to flatten a list of lists. The same syntax with curly braces builds a set or a dictionary.
pl: ## Listy zagnieżdżone i inne wyrażenia
Dwie części `for` w jednym wyrażeniu działają jak pętle zagnieżdżone – pierwsza jest zewnętrzna. To najszybszy sposób na spłaszczenie listy list. Ta sama składnia z nawiasami klamrowymi buduje zbiór albo słownik.
de: ## Verschachtelte Listen und andere Comprehensions
Zwei `for`-Teile in einer Comprehension wirken wie verschachtelte Schleifen – der erste ist der äußere. So flachst du eine Liste von Listen am schnellsten ab. Dieselbe Schreibweise mit geschweiften Klammern baut eine Menge oder ein Dictionary.
es: ## Listas anidadas y otras comprensiones
Dos partes `for` en una misma comprensión funcionan como bucles anidados: la primera es el exterior. Es la forma más rápida de aplanar una lista de listas. La misma sintaxis con llaves crea un conjunto o un diccionario.
fr: ## Listes imbriquées et autres compréhensions
Deux parties `for` dans une même compréhension fonctionnent comme des boucles imbriquées – la première est la boucle extérieure. C'est le moyen le plus rapide d'aplatir une liste de listes. La même syntaxe avec des accolades construit un ensemble ou un dictionnaire.

@code
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [n for row in matrix for n in row]
print(flat)
lengths = {word: len(word) for word in ['sun', 'moon', 'stars']}
print(lengths)
first_letters = {word[0] for word in ['apple', 'avocado', 'banana']}
print(sorted(first_letters))
@end

@md
en: ## Lambda functions
A **lambda** is a small function without a name, written in one expression: `lambda parameters: expression`. Its result is returned automatically – there is no `return`. Lambdas are handy where a function is needed only once, for example as the `key` for sorting.
pl: ## Funkcje lambda
**Lambda** to mała funkcja bez nazwy, zapisana w jednym wyrażeniu: `lambda parameters: expression`. Jej wynik jest zwracany automatycznie – nie ma `return`. Lambdy przydają się tam, gdzie funkcja jest potrzebna tylko raz, na przykład jako `key` przy sortowaniu.
de: ## Lambda-Funktionen
Ein **Lambda** ist eine kleine Funktion ohne Namen in einem einzigen Ausdruck: `lambda parameters: expression`. Das Ergebnis wird automatisch zurückgegeben – es gibt kein `return`. Lambdas sind praktisch, wo eine Funktion nur einmal gebraucht wird, zum Beispiel als `key` beim Sortieren.
es: ## Funciones lambda
Una **lambda** es una función pequeña sin nombre, escrita en una sola expresión: `lambda parameters: expression`. Su resultado se devuelve automáticamente; no hay `return`. Las lambdas son útiles donde una función solo se necesita una vez, por ejemplo como `key` al ordenar.
fr: ## Les fonctions lambda
Une **lambda** est une petite fonction sans nom, écrite en une seule expression : `lambda parameters: expression`. Son résultat est renvoyé automatiquement – il n'y a pas de `return`. Les lambdas sont pratiques là où une fonction ne sert qu'une fois, par exemple comme `key` pour trier.

@code
add = lambda a, b: a + b
print(add(2, 3))
square = lambda x: x ** 2
print(square(5))
words = ['banana', 'Kiwi', 'apple', 'Cherry']
print(sorted(words))                          # upper case first
print(sorted(words, key=lambda w: w.lower())) # ignore the case
print(sorted(words, key=lambda w: len(w)))    # by length
@end

pl: Rozpakuj w części `for`: `for country, capital in countries`. Wyrażenie słownikowe wygląda tak: `{key: value for ...}`.

print(upper)
print(by_country)

@hint
