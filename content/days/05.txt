en: ## Creating a list
A **list** is an ordered collection of values in square brackets. It can hold any types, even mixed, and it can change: you can add, remove and replace items. `len()` gives the number of items and `list()` turns other sequences into a list.

en: ## Reading and changing items
Items are numbered from `0`, and negative indexes count from the end, as with strings. Slices work too. You can assign to an index to replace an item, and `in` checks whether a value is in the list. **Unpacking** puts the items into separate variables; a starred name collects the rest.

Los elementos se numeran desde `0` y los índices negativos cuentan desde el final, como en las cadenas. También funcionan las porciones. Les éléments sont numérotés à partir de `0` et les indices négatifs comptent depuis la fin, comme pour les chaînes. Les tranches fonctionnent aussi. Affecter une valeur à un indice remplace l'élément, et `in` vérifie si une valeur est dans la liste. Le **déballage** répartit les éléments dans des variables séparées ; un nom étoilé récupère le reste.

@code
fruits = ['banana', 'orange', 'mango', 'lemon']

print(fruits[1:3])              # ['orange', 'mango']

print(fruits)
print('mango' in fruits)        # True
first, second, *rest = fruits
print(first, second, rest)      # avocado orange ['mango', 'lemon']
@end

en: ## Adding and removing items
These methods change the list itself:

| Method | What it does |
|---|---|
| `append(x)` | add `x` at the end |
| `insert(i, x)` | put `x` at position `i` |
| `extend(other)` | add all items of another list |
| `remove(x)` | remove the first `x` |
| `pop()`, `pop(i)` | remove and return the last item, or item `i` |
| `clear()` | remove everything |

`del fruits[0]` deletes an item by index. `count(x)` and `index(x)` tell you how many times `x` occurs and where it is first.
pl: ## Dodawanie i usuwanie elementów
Te metody zmieniają samą listę:

| Metoda | Co robi |

| `remove(x)` | usuwa pierwsze `x` |
| `pop()`, `pop(i)` | usuwa i zwraca ostatni element albo element `i` |

`del fruits[0]` usuwa element o danym indeksie. `count(x)` i `index(x)` mówią, ile razy występuje `x` i gdzie jest pierwszy raz.

@code
fruits = ['banana', 'orange']
fruits.append('mango')

en: ## Sorting, copying and joining
`sort()` sorts the list in place, and `sort(reverse=True)` in descending order; `sorted(list)` returns a new sorted list and leaves the original alone. `reverse()` turns the list around. `min()`, `max()` and `sum()` work on lists of numbers.

Careful with copies: `b = a` does **not** copy – both names point to the same list. Use `a.copy()` or `a[:]`. Two lists are joined with `+`.
pl: ## Sortowanie, kopiowanie i łączenie
`sort()` sortuje listę w miejscu, a `sort(reverse=True)` malejąco; `sorted(list)` zwraca nową, posortowaną listę i nie rusza oryginału. `reverse()` odwraca listę. `min()`, `max()` i `sum()` działają na listach liczb.

Uwaga na kopie: `b = a` **nie** kopiuje – obie nazwy wskazują tę samą listę. Użyj `a.copy()` albo `a[:]`. Dwie listy łączy się operatorem `+`.
de: ## Sortieren, kopieren und verbinden
`sort()` sortiert die Liste an Ort und Stelle, `sort(reverse=True)` absteigend; `sorted(list)` gibt eine neue sortierte Liste zurück und lässt das Original unverändert. `reverse()` dreht die Liste um. `min()`, `max()` und `sum()` funktionieren mit Zahlenlisten.

Vorsicht beim Kopieren: `b = a` kopiert **nicht** – beide Namen zeigen auf dieselbe Liste. Nimm `a.copy()` oder `a[:]`. Zwei Listen verbindest du mit `+`.
es: ## Ordenar, copiar y unir
`sort()` ordena la lista en su sitio, y `sort(reverse=True)` en orden descendente; `sorted(list)` devuelve una lista nueva ordenada y deja intacta la original. `reverse()` le da la vuelta a la lista. `min()`, `max()` y `sum()` funcionan con listas de números.

Cuidado con las copias: `b = a` **no** copia; los dos nombres apuntan a la misma lista. Usa `a.copy()` o `a[:]`. Dos listas se unen con `+`.
fr: ## Trier, copier et assembler
`sort()` trie la liste sur place, et `sort(reverse=True)` par ordre décroissant ; `sorted(list)` renvoie une nouvelle liste triée sans toucher à l'originale. `reverse()` retourne la liste. `min()`, `max()` et `sum()` fonctionnent sur des listes de nombres.

Attention aux copies : `b = a` ne copie **pas** – les deux noms désignent la même liste. Utilise `a.copy()` ou `a[:]`. Deux listes s'assemblent avec `+`.

@code
ages = [19, 22, 19, 24, 20, 25, 26, 24, 25, 24]
print(sorted(ages))
print(min(ages), max(ages), sum(ages) / len(ages))
a = [1, 2, 3]
same = a
copy = a.copy()
a.append(4)
print(same, copy)          # [1, 2, 3, 4] [1, 2, 3]
print([1, 2] + [3, 4])     # [1, 2, 3, 4]
@end
